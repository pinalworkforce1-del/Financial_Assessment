# BOOST Financial Stability Module

A lightweight, GitHub Pages-ready financial stability / support-services module for BOOST.

## Included assets
- `assets/financial-literacy-hero.png` — BOOST graphic-novel header image
- `assets/rosie-financial-guide.png` — Rosie intro visual
- `assets/rosie-financial-barriers.mp3` — Rosie introduction audio
- `assets/rosie-financial-barriers.vtt` — subtitle/caption track from VEED

## What it does
- Adds a BOOST graphic-novel hero image
- Adds a Rosie intro section with audio, captions, and exact-match transcript
- Provides simple monthly “Money In” and “Money Out” entry
- Adds hints/examples under each expense category
- Calculates estimated amount left
- Uses neutral, non-judgmental feedback
- Lets participants identify practical barriers worth discussing
- Produces a printable Financial Stability Snapshot
- States that participation is voluntary, but required prior to issuing support services

## Deploy to GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html` and the full `assets` folder.
3. In GitHub: **Settings → Pages → Deploy from branch → main / root**.
4. Use the published Pages URL in the BOOST home map.

## Notes
The current version stores no participant data outside the browser.
